# RPSExtreme 🎮

A command-line Rock Paper Scissors game built with Python.

## How to Play

Run the game and enter your choice when prompted:

The computer will randomly pick its choice and the winner will be decided. After each round you can choose to play again or quit.

## Rules

- Rock smashes Scissors ✅
- Scissors cuts Paper ✅
- Paper covers Rock ✅

## Requirements

- Python 3.x

## Running the Game

**From source:**
```bash
python RPSExtreme.py
```

**As an executable (Linux):**
```bash
chmod +x dist/RPSExtreme
./dist/RPSExtreme
```

## Building the Executable

```bash
pip install pyinstaller
pyinstaller --onefile RPSExtreme.py
```
